# --- Shoulder (Y/X/Z): Up/Down (Y) | Left/Right (X) | C/V (Z)
# UP / DOWN: Shoulder Y-Axis (Vertical)
# LEFT / RIGHT: Shoulder X-Axis (Lateral)
# C / V: Shoulder Z-Axis (Rotation/Azimuth)

# --- Elbow (Flexion): Z (close) / S (open)
# Z / S: Elbow X-Axis (Bending/Straightening)

# --- Wrist (Flex/Dev): Q/D (Flexion) | W/X (Deviation)
# Q / D: Wrist X-Axis (Flexion)

# --- SPEED MODIFIER ---
# SHIFT: Fast Speed
# CTRL: Slow Speed

# --- HAND AND SYSTEM CONTROLS ---

# --- Hand (Close/Open): F/G
# F: Close Grip / GRAB (Activates 'Glue' Constraint if in contact)
# G: Open Grip / RELEASE

# --- Arm (IK/Autograb): H
# H: Inverse Kinematics Mode (Attempts to align arm towards cup)

# --- Arm (Toggle HUD): T
# T: Toggle Tactical Overlay (Distance, Target Info)

# --- Camera (Toggle View): TAB
# TAB: Switch Camera View (Orbit <-> Shoulder FPS)

# --- System (Reset/Quit) ---
# SPACE: Reset Robot and Cup
# ESC: Quit Simulation
